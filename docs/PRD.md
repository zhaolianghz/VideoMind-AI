## 一、产品概述

### 1.1 产品定位

本产品并非传统的"视频下载工具"，而是一款 **AI视频情报分析桌面 Agent**。核心价值在于将各主流平台的视频自动采集、转文字、深度语义理解，最终生成结构化报告并提取知识资产，成为企业和个人的"AI版视频研究员"。

### 1.2 核心价值链

```
视频URL输入 ➔ 视频/音频采集 ➔ ASR语音识别 ➔ AI多模态理解 ➔ 结构化报告生成 ➔ 企业/个人知识库沉淀
```

### 1.3 核心业务流程

```
用户输入视频URL
        │
        ▼
┌───────────────────┐
│ 视频采集引擎       │  yt-dlp + 反爬策略
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ 多媒体处理管线     │  FFmpeg + faster-whisper
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ AI分析引擎        │  多模型协同 + RAG知识库
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ 报告生成系统       │  模板引擎 + 多格式输出
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ 知识库与资产积累   │  向量数据库
└───────────────────┘
```

## 二、用户画像与使用场景

### 2.1 企业市场部
- **需求**：分析竞品视频内容、发布会策略。
- **场景**：输入竞品发布会视频，输出商业模式、核心卖点、营销策略分析报告。

### 2.2 培训机构/讲师
- **需求**：拆解长视频课程，提炼教学逻辑。
- **场景**：输入3小时商业课程，输出课程大纲、知识点、案例库及二次开发方向。

### 2.3 内容创作者/MCN
- **需求**：研究爆款视频规律，指导内容创作。
- **场景**：批量输入100条同行爆款视频，输出标题规律、开头3秒钩子、内容结构、用户痛点及可复制模型。

### 2.4 学生/研究人员
- **需求**：高效学习视频资料，提取学术信息。
- **场景**：将学术讲座视频转为结构化笔记和思维导图。

## 三、功能需求详细说明 (V1.0 - V2.0)

### 3.1 视频采集引擎模块

**目标**：稳定、高效地下载各平台视频及元数据。

- **支持平台**：
  - 一期：YouTube、B站、抖音、快手、小红书、TikTok。
- **输入方式**：
  - 单视频模式：粘贴视频URL，点击"开始分析"。
  - 批量模式：上传包含多个URL的txt文件，系统排队批量分析。
- **鉴权与反爬**：
  - 支持用户导入本地浏览器 Cookie（解决会员视频、登录限制）。
  - 针对抖音/快手等强反爬平台，支持移动端 UA 模拟与请求头伪装。
- **元数据获取**：自动抓取视频标题、作者、发布时间、播放量、封面图。

### 3.2 视频处理与ASR模块

**目标**：将视频转化为AI可读的文本及时间轴数据。

- **音频分离**：基于 FFmpeg 提取音频，统一转码为 16kHz 单声道 MP3/WAV。
- **语音识别 (ASR)**：
  - 采用本地化部署的 faster-whisper 模型，支持 GPU 加速。
  - 支持模型自适应：根据视频时长和硬件配置自动选择 tiny/base/small/medium 模型。
  - 输出带精确时间戳的文本块。
- **字幕生成**：将识别结果格式化为 SRT/VTT 字幕文件，支持与视频时间轴对齐。

### 3.3 AI分析引擎模块（核心）

**目标**：基于多模型路由和 Prompt 模板，进行深度内容理解。

- **模型路由层**：
  - 支持配置多个大模型 API（GPT-4o, Claude 3.5, 通义千问, DeepSeek）。
  - 根据任务类型动态选择：通用摘要用 GPT-4o，长文本深度分析用 Claude，中文优化用通义千问。
- **基础分析模式**：
  - 视频摘要：提炼视频主要讨论内容（300字以内）。
  - 核心观点：提取3-5个核心论点及支撑论据。
- **深度分析模板**（用户可下拉选择）：
  - **商业模式分析**：输出目标用户、盈利方式、增长策略、竞争优势、风险与机会。
  - **课程拆解分析**：输出章节大纲、知识点列表、案例库、教学逻辑、适合人群。
  - **爆款规律分析**：输出标题规律、封面分析、前三秒情绪钩子、内容结构、传播机制、复制模型。
- **多模态理解 (V2.0)**：
  - 关键帧提取：FFmpeg 按场景切换提取关键帧。
  - OCR识别：识别画面中的 PPT、白板、数据图表文字。
  - 将 OCR 文本与 ASR 文本合并进行综合分析。

### 3.4 报告生成中心

**目标**：将AI分析结果结构化、可视化输出。

- **Markdown报告**：标准结构化报告，包含视频信息、摘要、核心观点、深度分析详情。
- **PDF报告**：将 Markdown 渲染为企业级风格的 PDF 文档（支持自定义 Logo 和样式）。
- **导出位置可配置**：报告导出（MD/HTML/PDF）默认存入用户在「设置」配置的报告目录（未配置则存系统下载目录）；每份报告支持「另存为…」临时选择保存位置。数据总表 CSV 导出同样遵循该报告目录。
- **PPT汇报 (V2.0)**：一键将分析结果生成商业汇报 PPT，使用 python-pptx 填充预设模板。
- **思维导图 (V2.0)**：输出 Markdown 格式思维导图，兼容 XMind 等软件。

### 3.5 知识库系统（V2.0引入，V3.0完善）

**目标**：将单次分析转化为长期知识资产。

- **本地向量库**：采用 Chroma 存储所有分析过的视频文本块及摘要向量。
- **RAG检索增强**：分析新视频时，可勾选"参考历史知识"，系统自动检索本地知识库相关内容注入 Prompt。
- **智能问答**：支持针对已分析的视频库进行自然语言提问（如："过去一个月我分析的竞品视频，都有哪些定价策略？"）。

### 3.6 本地存储管理（V1.0）

**目标**：让用户掌控占空间的视频文件与报告导出的落盘位置。

- **媒体目录可自定义**：下载的音视频默认存放在系统应用数据目录下的 `media/`；用户可在「设置 → 存储目录」改为任意本地路径（如外置硬盘、D 盘）。更改后已下载的视频仍在原位置可正常访问，新下载的视频落入新目录。
- **报告目录可自定义**：报告导出（MD/HTML/PDF）与数据总表 CSV 的默认落盘位置可在「设置 → 存储目录」配置；未配置时存入系统下载目录。
- **目录选择**：桌面端通过原生目录选择框选路径；浏览器调试模式不支持，打包后可用。
- **内部数据不开放自定义**：封面、字幕、Cookie、数据库等应用内部数据始终跟随应用数据目录，不与用户视频混存。

## 四、界面与交互说明（桌面端）

### 4.1 主界面布局

采用左侧导航栏 + 右侧内容区的经典布局。

- **左侧导航**：
  - 🏠 首页工作台
  - ➕ 新建分析任务
  - 📂 视频库
  - 📊 报告中心
  - 🧠 知识库问答 (V2)
  - ⚙️ 设置（模型配置、Cookie导入、存储目录）

### 4.2 核心交互流程

- **新建任务**：点击"新建分析" ➔ 粘贴URL或导入TXT ➔ 选择分析模式（摘要/商业/爆款等） ➔ 点击"开始"。
- **进度监控**：任务卡片实时显示状态（排队中/下载中/转码中/识别中/AI分析中/完成）。支持后台运行。
- **结果查看**：点击完成任务，右侧分栏显示：左侧为视频播放器及字幕，右侧为生成的报告内容。支持编辑修改报告。
- **报告导出**：在报告详情页点 MD/HTML/PDF 直接导出到默认报告目录；点「另存为…」临时选择保存位置。

## 五、非功能需求

### 5.1 性能要求
- **并发处理**：支持至少3个任务并发下载和处理（受限于本地带宽和GPU算力）。
- **处理速度**：1小时视频，在本地 GPU 加速下，ASR识别应在5分钟内完成；AI分析应在2分钟内完成。
- **长视频支持**：必须支持3小时以上长视频的稳定处理（切片处理及长上下文模型支持）。

### 5.2 安全与稳定性
- **本地优先**：敏感数据（如视频文件、ASR文本）默认保存在本地，仅调用云端API时传输必要的文本数据。
- **断点续传**：视频下载支持断点续传；任务队列异常中断后可恢复执行。
- **API容错**：大模型API调用失败时，自动重试并切换备用模型。

### 5.3 跨平台支持
- 桌面端需同时支持 **Windows (10及以上)** 和 **macOS (12及以上)** 系统。

## 六、技术架构与选型规划

### 6.1 整体技术栈
- **桌面客户端**：Tauri (Rust + Vue3/React) —— 轻量、低内存占用。
- **后端服务**：Python + FastAPI —— 高性能异步API。
- **任务队列**：Celery + Redis —— 处理耗时的下载和AI分析任务。
- **本地数据库**：SQLite（元数据）+ Chroma（向量数据）。

### 6.2 核心组件选型
| 组件 | 选型 | 说明 |
|------|------|------|
| 下载引擎 | yt-dlp | 支持1000+站点，持续更新 |
| 音视频处理 | FFmpeg | 行业标准 |
| 语音识别 | faster-whisper | CTranslate2加速版，支持INT8量化 |
| 大模型接入 | OpenAI / Anthropic / 阿里云百炼 / 深度求索 | 支持标准API格式 |

## 七、版本演进路线图

### V1.0 MVP版（目标：能跑通、能卖）
- 支持主流平台单/批量URL下载。
- 本地 Whisper 语音转文字。
- 基础摘要 + 1-2个深度分析模板。
- Markdown 及 PDF 导出。
- 单机授权激活。

### V2.0 专业版（目标：建壁垒、提客单）
- 增加多模态理解（关键帧OCR）。
- 完善所有深度分析模板（课程、爆款、商业）。
- PPT 及思维导图生成。
- 引入本地 Chroma 向量库，实现单机 RAG 问答。

### V3.0 企业版（目标：ToB化、知识资产化）
- 企业私有化部署（Docker集群）。
- 替换为 Milvus 亿级向量数据库。
- 多账号协同与权限管理。
- 企业专属品牌模型微调（基于历史数据分析）。
- API 开放平台。

### V4.0 Agent平台版（目标：生态化）
- 从工具升级为"AI增长OS"。
- 自动监控竞品账号，主动抓取并生成周报。
- 结合 CRM，从视频评论中提取销售线索。
- 行业模型商城（教培、房地产、SaaS专属分析模型）。

## 八、商业化模式设计

### 8.1 定价策略

| 版本 | 定价 | 核心权益 | 目标用户 |
|------|------|----------|----------|
| 个人版 | ¥39-99/月 | 每月10-30个视频，基础摘要，MD导出 | 学生、个人创作者 |
| 专业版 | ¥299/月 | 无限视频，所有深度模板，PPT导出，本地知识库 | 研究员、自媒体团队 |
| 企业版 | ¥9999-99999/年 | 私有部署，团队协同，API接口，定制模型 | 企业市场部、培训机构 |

### 8.2 核心护城河
- **数据飞轮**：积累百万级视频分析记录，训练出懂行业的专用模型，通用工具无法直接超越。
- **企业知识图谱**：企业越用，AI越懂其业务，迁移成本极高。
- **工作流深度集成**：从单纯的分析工具，变成企业内容营销、竞品情报获取的基础设施节点。
